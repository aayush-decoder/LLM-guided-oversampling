## Responsibility
Documents all reproducible terminal commands for running the project:
- Environment and system audits (`python -m tabgen audit env`).
- Dataset download and inspection (`python -m tabgen data download`).
- Smoke testing pipelines (`python -m predllm_v1 smoke`, `python -m predllm_v2 smoke`).
- Running experiments, training, generation, inference, and reporting across v1 and v2 pipelines.
