# palt: LLM Tabular Data Generation (Pred-LLM v1 → v2)

> Root project documentation stub.

## Responsibility
Serves as the central entry point and architectural guide for the repository:
- Outlines the monorepo structure: `common/tabgen` (shared foundation), `v1/predllm_v1` (faithful replication of Pred-LLM / arXiv:2410.21717), and `v2/predllm_v2` (extended methods with schema-constrained decoding and exact posteriors).
- Maps where LLMs are used across training, sampling, and querying phases.
- Provides quick-start instructions for environment setup, data downloading, smoke testing, and benchmark evaluation.
